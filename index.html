⚙️ Firebase Setup Required

To save picks across devices in real time, you need to connect a free Firebase database. This takes about 5 minutes to set up once.

  1. Go to console.firebase.google.com
  2. Create a project → click Add Web App → copy the config object
  3. Go to Firestore Database → Create database → Start in test mode
  4. Open index.html and replace the FIREBASE_CONFIG block at the top of the <script>
  5. Commit & push — GitHub Pages will auto-deploy in ~1 min
Firebase API keys are safe to commit publicly — control access with Firestore security rules.
